# 폰컨트롤 (PhoneLock)

앱을 그룹으로 묶어 일일 사용 시간 한도와 시간대 스케줄로 잠그고, 지정한 앱은 실행 전 확인창을 띄우는 Android 앱.

## 실행 방법
1. Android Studio(최신 버전)에서 `phone-lock-android` 폴더를 "Open" 으로 엽니다.
2. Gradle Sync가 자동으로 실행됩니다 (Gradle Wrapper jar가 없으므로 Android Studio가 처음 열 때 자동으로 받아옵니다).
3. 실제 기기 또는 에뮬레이터(Android 8.0/API 26 이상)에서 Run.
4. 앱 실행 후 **설정 탭 → 접근성 설정 열기**에서 "폰컨트롤" 접근성 서비스를 켜야 그룹 잠금/실행 확인 기능이 동작합니다.

## 기능
- **그룹 탭**: 앱들을 그룹으로 묶고, 그룹별로 일일 사용 한도(분)와 요일별 차단 시간대를 설정
- **확인 목록 탭**: 특정 앱을 열 때마다 "정말 실행하시겠습니까?" 확인창 표시
- **설정 탭**: 접근성 서비스 활성화 상태 확인 및 설정 이동

## 참고
- 이 프로젝트는 샌드박스 환경(Android SDK 없음)에서 작성되어 실제 빌드/실행 검증은 하지 못했습니다. Android Studio에서 빌드 시 오류가 발생하면 알려주시면 수정하겠습니다.
